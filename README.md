🚨 What's in the Vault?

📊 The Research Database: Fully interactive in-browser CSV parser tracking election performance (2014–2026) and corruption/controversy news records without cooking the stats. Allegation ≠ Conviction, period.

📡 Live X / Twitter Monitor: Automated streams tracking over 50+ political accounts across the spectrum (INC, BJP, NDA, Left, and Official Government bodies like PIB and ISRO).

🎮 "Are You Democracy Literate?": A 50-question randomized trivia gauntlet testing if visitors actually passed Indian political history.

🕵️‍♂️ The Editorial Desk: A protected human-in-the-loop review pipeline so AI-generated political claims never get auto-published. (Locked behind ?editor=true with your secret PIN).

🇮🇳 Bharat Ke Veer Portal: 100% of all community contribution prompts route directly to the official Ministry of Home Affairs gateway for the Indian Armed Forces.

🛠️ Tech Stack & Architecture

Frontend: React, Tailwind CSS, Lucide React icons, and modern Gen-Z color palettes (Digital Lavender, Electric Blue, Slate Blue-Gray).

Database: Supabase (PostgreSQL) for accounts, dynamic live feeds, and quiz pools.

Backend Ingestion: Vercel Serverless Functions & Daily Cron Job architecture (vercel.json).

Deployment: Hosted live on Vercel.
